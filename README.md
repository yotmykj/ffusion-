# FFFusion

A modern Android TV launcher with glassmorphic UI inspired by Fusion OS, Google TV, and tvOS.

## Features

- **Modern Material 3 Design**: Clean, contemporary interface with glassmorphism effects
- **Full D-pad Support**: Complete Android TV remote compatibility
- **Smooth Animations**: 400ms focus animations with gradient shadows
- **Responsive Layout**: Row and grid layouts for app organization
- **Dark Theme**: Optimized for TV viewing
- **Wallpaper Support**: Custom wallpaper integration
- **Firebase Integration**: Analytics and crash reporting

## Design Highlights

- Indigo-Purple gradient accent color (#667EEA - #764BA2)
- Glassmorphic header with backdrop blur
- Smooth scale and elevation animations on focus
- Professional spacing and typography
- Category section headers with gradient accent bars

## Building

```bash
flutter pub get
flutter run
```
